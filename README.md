# 康奈尔日记 · 工作生活记录与复盘

参考康奈尔笔记法原则打造的**个人日记系统**，单文件 HTML 应用，双击即可使用，无需安装。

## 功能亮点

- **每日记录**：情绪 / 精力 / 成就感三档评分 + 线索 Cue + 关键词 + 高光时刻 + 待跟进问题
- **图片附件**：支持图片与附件上传、拖拽、Ctrl+V 粘贴，存储于浏览器本地（IndexedDB）
- **AI 自动复盘**：本地智能引擎，数据不出浏览器——周/月复盘自动生成初稿，含上周对比、执行力分析、状态模式识别与针对性建议，二次修改即完成复盘
- **行事历**：月历视图 + 待办管理，未完成任务自动顺延至完成，支持循环任务（每天/每周/每月）、完成备注、设定/完成日期与用时统计
- **数据安全**：所有数据仅存于浏览器本地（localStorage / IndexedDB），不经过任何服务器；可随时导出备份

## 使用说明

1. 直接打开本页即可使用
2. 每日记录完成后，去「每周复盘」「每月复盘」点「AI 自动复盘」生成初稿
3. 数据跨设备迁移：使用系统内「导出备份」/「导入备份」功能

## 隐私说明

本应用为纯前端单文件应用，**不含任何后端，不上传任何数据**。每个使用者的数据仅保存在各自浏览器本地，互不可见。
